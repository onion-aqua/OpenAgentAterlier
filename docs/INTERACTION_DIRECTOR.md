# 连续互动演出

参考任务“对比 RyzaChat 版本更新”中的目标：按语境配合表情与动作，避免随机摆动。

运行时将语义动作和当前表情成对入队，等待上一个原资源动作与过渡完成，再播放下一个。队列最多保留两个意图，五秒后过期；相同意图去重，保持三秒动作冷却。

触碰、换装、取消播放与情绪改变会清理旧队列。触碰反馈优先；说话保持原资源表情组合、眨眼与音量驱动口型；动作期间不随机换脸。

动作继续使用原资源轨道、权重、速度、过渡参数和姿态兼容检查。不把多个占用同一手臂轨道的动作强行同时叠加，先采用顺序演出。

局限：仍需在设备上校准各套服装的具体组合；新版 GesturePatternDefs 与 AttitudePatterns 的完整编排尚未全部替代现有语义映射。不能仅凭标签名称保证一定表现为伸手或挠脸。
