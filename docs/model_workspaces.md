# 模型档案与独立数据

应用以用户导入的模型为聊天对象。Spine、Live2D 共用一个模型库；每个导入条目拥有独立的模型 ID、人物档案和应用数据。切换模型会保存当前档案，再读取目标模型的档案。重新导入同一份资源会创建另一个模型条目，适合建立独立角色；它不会按文件名覆盖已有聊天。

## 使用

1. 在模型库导入资源，或打开「设置 → 模型档案与数据 → 导入模型或模型与数据 ZIP」。虚拟手机中的「模型姿态」也提供模型选择入口。
2. 原始资源选 Spine 或 Live2D。恢复本应用导出的压缩包时选「模型与数据 ZIP」。两条路径仍需完成本地扫描、LLM 动作映射与用户确认；包中已有映射会作为已有资料供适配流程使用，不会跳过资源与运行库兼容检查。参见 [模型映射](model_mapping.md)。
3. 在模型库选择并切换模型。在「模型档案与数据」可修改当前角色名称；用户设定、人物设定和世界设定仍在各自的设置页面编辑。
4. 选择「导出模型与数据 ZIP」保存可迁移的模型档案。导出前会等待当前模型的数据写入完成。未选择模型时导出按钮不可用。
5. 在另一设备配置 AI/语音服务后，导入该 ZIP，完成映射并切换到新导入条目。包中的会话和存档会重新绑定新条目的模型 ID。

LLM 映射分析使用当前配置的 AI 接口，可能产生调用费用。它识别可用的动作、表情和参数；不会自动替用户编造人物经历或完整世界。新模型从独立档案开始，未设定的身份、关系和世界背景不沿用其他模型的事实。

## 哪些数据跟随模型

| 内容 | 保存范围 |
| --- | --- |
| 角色名称与提示词 | 角色名称；用户档案与设定槽；人物、世界设定及其注入开关 |
| 聊天与记忆 | 当前主聊天的原文与已保存译文；近期记忆、长期记忆及整理进度 |
| NPC 信息 | 已交换的联系方式、NPC 聊天记录及已有译文 |
| 剧情状态 | 人物状态、关系、物品、剧情时钟、当前地点、已有任务与炼金进度等受支持状态 |
| 存档 | 当前模型的六个本地存档槽和活动槽位 |
| 对话语言与发声偏好 | 回复/旁白/翻译语言、独立翻译与译文显示方式；普通/ASMR 音色 ID、部分语速/情绪/表现设置 |
| 收藏与语音缓存 | 按模型隔离存储；目前仍由收藏模块单独管理和导出，不写入模型 ZIP |

AI 与语音服务的连接属于设备配置：切换模型保留当前设备使用的服务商、服务地址、模型选择和鉴权。音色 ID 随模型保存，与服务连接分开处理。模型包中的人物/世界文本不会安装新的地图、场景资源或程序插件。

## ZIP 结构和导出边界

```text
manifest.json                    # agent-atelier-model-package，version 1
model/                           # 已接入的模型运行文件、预览与动作映射
app/session.json                 # 当前模型的名称、设定与会话快照
app/save_slots.json              # 当前模型的存档槽
app/attachments/texture.png       # 可选，自定义替换贴图
app/attachments/texture-state.json # 可选，替换贴图启用状态
```

模型 ZIP 包含上述受支持的模型数据，不能代替整个应用的完整备份。当前不包含：

- API Key、OAuth/设备 token、PC Agent 配对凭证、服务地址及服务连接配置。
- 聊天上传的图片/文件原件、独立缩略图缓存；消息保留附件描述，不保证换设备后仍能显示原附件。
- 收藏的文本与语音、临时 TTS 音频缓存、本地 TTS 模型文件、音色克隆参考音频和设备本地路径。
- 壁纸、单独导入的场景/座椅、语音闹钟、界面主题、音量、后台服务与设备权限配置。

收藏请使用收藏页面的导出功能；本地语音模型和参考音频需在目标设备另行准备。普通「导出本地数据」、单存档导出和模型 ZIP 导出用途不同，不应互相替代。包中仍包含对话和人物资料，分享前请检查内容。

保存采用串行写入和临时文件替换，已压缩的模型资源在更新会话时复用；播放器使用独立展开缓存，缺失时可从模型 ZIP 恢复。压缩包损坏时不会用空档案覆盖原包。包格式校验包括路径、重复项、文件数量、展开体积、CRC 和模型资源 SHA-256；这些校验用于确认结构与内容完整性，不是来源签名。

模型 ZIP 上限为 256 MB、总展开内容上限 512 MB、单个模型文件上限 128 MB、各应用状态 JSON 上限 32 MB、最多 1024 个 ZIP 条目。具体运行格式还受导入器限制，例如 Spine 资源包和展开内容各不超过 64 MB。VRM 目前可扫描与生成映射，尚无可导入播放的渲染器。

## 旧版本迁移

旧模型的展开文件与索引会转为模型 ZIP，并保留原资源路径兼容信息。第一次启动此版本时，如果当前选择的已经是一个已导入模型，当前旧会话和原角色存档会迁移到这个模型；空的人物/世界设定会在迁移时固化其当时实际使用的默认文本。已有资料不会复制给模型库里的每个条目。

其他模型在首次使用时创建独立档案，原应用角色的旧资料仍保留。旧版本没有按模型保存历史，程序无法可靠猜出一段旧聊天原本属于哪个未选中的模型。需要保留旧资料时应先导出旧数据，并检查迁移后的模型名称、提示词、聊天与存档。

以后单纯切换模型不会触发全局旧数据迁移；带数据的模型 ZIP 按包内内容恢复，原始资源导入创建新档案。服务鉴权和其他设备设置继续保留在设备侧。
