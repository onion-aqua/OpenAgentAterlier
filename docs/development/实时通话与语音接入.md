# 实时通话与语音接入

本文描述 `D:\OpenAgentAtelier` 提纯版的实际实现。电话不依赖内置人物，普通与 ASMR 音色必须由用户在当前模型的“声音与语音”中配置。不得使用旧存储 owner ID 选择人物、音色、头像或世界。

## 平台与依赖

- Android：本地语音识别、流式电话和主聊天麦克风面板可用。入口由 `AppPlatformCapabilities.supportsRealtimeCalls` 控制。
- Windows：保留普通云 TTS、MCP、ASMR；目前没有实时电话 PCM 原生桥，不显示电话和麦克风入口。不要用宿主操作系统判断目标平台。
- Dart 依赖：`record: ^7.1.2`、`sherpa_onnx: 1.13.8`。Android 需要 `RECORD_AUDIO` 与 `RealtimePcmBridge` 注册。实际麦克风权限只在用户发起通话后获取。
- 电话当前支持 Fish Audio REST 或 Fish Audio MCP。其他 TTS 提供商继续用于普通聊天，电话不隐式切换计费服务。

## ASR 与本地模型

设置入口为电话页的通话设置。准备三个非空文件：SenseVoice `model.int8.onnx`、匹配模型的 `tokens.txt`、`silero_vad.onnx`。`CallSettingsStore` 只保存本地路径与配置；API Key 始终通过 `SecretStore` 获取。可选择文件或通过 `CallAsrModelDownloader` 下载公开 ASR 模型；下载器校验字节大小和 SHA-256，分阶段落盘，失败或取消时清理临时文件。没有在本次移植中实际下载模型。

`LocalCallAsrConfig.validateFiles()` 在获取麦克风之前验证路径、文件非空、语言和静音断句参数。语言为 `auto/zh/en/ja/ko/yue`；静音时长默认 0.65 秒，可在 0.3–2 秒内设置。录音输入为 16 kHz、单声道 PCM16；Sherpa 与 VAD 在独立 worker 中运行。`LocalCallAsrGate` 与 `LocalCallEchoFilter` 控制静音、播放期间回声、结束后残留与用户插话。新增 ASR 实现应实现 `LocalCallAsrEngine`，不得在 UI isolate 同步执行模型推理。

## 电话会话与模型隔离

`RealtimeCallController` 统一拥有录音、识别、LLM 流、TTS 流及播放器。通过构造器注入 `LocalCallAsr`、`CallPcmOutput`、`CallReplyBackend`、`CallSettingsStore`、语音工厂和 Key 读取器，测试可以保持离线。

联系人只来自当前已导入模型，ID 为 `primary:${app.activeConversationScopeId}`，显示名称来自 `activeCharacterProfile`，头像通过 `CallContactAvatar` / `CharacterAvatar` 使用当前模型预览；缺少图片时使用名称或中性图标。重命名不改变稳定 ID。没有模型或普通音色时提示先配置；不会借用其他模型的声音。

每次通话、每轮回复都带 epoch，并检查 `AppController.dataRevision`。换模型、换存档、后台、挂断、系统来电、切换语音服务或数据重置会取消旧操作并释放麦克风/音频。恢复后的旧网络结果不能重启播放，也不能写入新模型。新扩展必须保留 `addDataResetListener(prepareForDataReset)` 与对应移除操作。

`CallRecord` 仅保存识别文本、真正播放完成的台词与通话元信息，不录制原始麦克风。`recordCallExchange(..., expectedRevision:)` 只提交已经播放的内容；主角内部标签固定为 `主角：`，UI 按当前模型转换名字。`callRecords`、记忆和普通/ASMR 音色随模型包与本地存档保存，`history` 额外按当前联系人 ID 过滤。旧用户音色配置不会被一次性迁移清除；历史文本不改名。

## TTS 有序预取与限流

普通聊天和持续 ASMR 使用 `OrderedSpeechPreparation<T>`。云 TTS 最多同时准备 2 段，按原文本顺序消费，先完成的后句不能提前播。ASMR 还通过 `capacity` 把缓冲与待处理片段总量限制在可用空间内。本地 TTS 使用 1 路。`SpeechConcurrencyPolicy.observe()` 收到 429 后降低该 provider 当前进程内的后续并发至 1，不重新提交被拒绝的同次生成。

电话用 `CallSpeechPrefetch` 提前准备最多两句，播放仍单路、顺序、可取消。`CallAudioPriority` 暂时压低背景与场景音频；AudioTrack 固定消费 24 kHz PCM。`CallPcmOutput.start/write/drain/stop/setSpeaker` 是原生桥契约。不得用模拟能量、播放器速度或重叠播放代替真实 PCM 排空。

提交结果未知、连接中断、超时或播放处理失败都不自动重新发起付费合成。桌面代理路由在下一次用户显式请求时重新探测；一次请求不同时向直连和代理重放。音频检查失败保持文本可读，并按照既有拒绝预算终止连续无效片段。

## Fish 标签、ASMR 与语速

- `scopeFishAsmrDelivery` 为整段台词建立一次耳语基底，保留说话正文，删除喘息、吸气、呼气等呼吸表演标签。明确关闭演出标签时不添加基底。
- Drama 3：`compileFishDrama3Text` 将内部语义标记编译成官方成对标签，例如整段 `<whisper>…</whisper>`。
- S2：仅 `s2-pro`、`s2.1-pro`、`s2.1-pro-free` 走 `compileFishS2Text`，把明确耳语方向编译成完整的描述式方括号。未知模型不猜测 S2 方言。
- 标签协议与角色身份分离；使用哪种标签不授权选择任何固定音色。普通音色、ASMR 音色均从当前模型配置读取。
- Fish 默认语速在支持的处理路径为 0.9，已有非默认用户设置保留。Windows 目前保留原速默认值，避免压缩音频不能解码造成不可播放。
- MCP 工具支持服务端 speed 时使用该参数；不支持时由 `adjustSpeechFileTempo()` 调用 `changeSpeechWavTempo()` 在 isolate 中做 WSOLA 保音高变速。Android 压缩音频可先经 `agent_atelier_r/speech_envelope` 的 `decodeWav` 解码。其他平台需 WAV；不支持时明确失败，不重新生成或偷偷变调。
- 处理前后检查取消回调和内存/时长上限；原始文件所有权归调用者，中间与失败文件由处理器清理。

## MCP 恢复

`FishMcpRestoreCoordinator` 在应用首帧后启动，前台恢复、切换到已启用 MCP provider 时最多尝试一次。普通 controller 通知不形成重连循环。它调用 `FishMcpService.restoreConnection()`，只恢复已有 OAuth 与读取工具，不打开浏览器、不注册客户端、不提交合成。聊天/ASMR/电话提交语音前也会尝试恢复。

`restoreConnection()` 是单飞请求。手动 `disconnect()` 禁止后续自动连接；用户显式 `connect()` 或重新授权才恢复资格。OAuth 失效时提示到设置登录。回调固定为 `agentatelier-fishmcp://oauth/callback`，Android/Windows/Dart 必须保持一致。凭据不写入日志、模型包或普通备份。MCP 到 REST 只按用户原有自动回退开关与明确可安全回退的错误进行；电话始终禁止自动改用 REST。

## 睡眠、人物与演出接入

冷启动睡眠仅针对已选模型。唤醒按钮显示当前模型名称，等待唤醒期间不启动电话、麦克风、发送或 ASMR。兼容 Spine 操纵模板只有真实资源存在时才使用睡眠脸部和起身动作；通用映射 Spine、Live2D 或静态模型走中性点击反馈后解锁，不假装播放旧骨架动作。

人格通过独立表情/动作/声音规划器的 `sharedContext.personality_preferences` 传递，每个规划器只读取自己的维度。它属于低优先级偏好，不能覆盖本轮用户边界、语言、合法动作能力或声音配置。切换模型后重新生成能力目录和人格上下文。

## 验证与扩展

核心离线回归包括 `test/realtime_call/`、`main_chat_voice_entry_test.dart`、`fish_mcp_autoconnect_test.dart`、`fish_mcp_restore_coordinator_test.dart`、`fish_mcp_speed_test.dart`、`fish_s2_tags_test.dart`、`fish_asmr_delivery_test.dart`、`speech_tempo*_test.dart`、`ordered_speech_preparation_test.dart` 与 `personality_performance_test.dart`。电话 provider 测试使用真实临时模型包验证同 owner 下不同模型的音色/记录隔离、改名、等待 MCP 时切换模型取消，以及两句预取的顺序。

这些回归不代表真实麦克风、实际模型识别准确率、蓝牙路由、真机后台或付费端点验收已完成。移植阶段没有构建、安装、调用付费语音接口或发布。
