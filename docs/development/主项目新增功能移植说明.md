## 必须保持的提纯边界

- 显示名称 `OpenAgentAtelier`，无自定义应用图标和启动 Logo；人物文字、头像、通知和生成提示取当前模型资料，缺失时用中性默认值。
- 虚拟手机保留 `alchemy` 技术路由，显示“背包 / Inventory”；不因导入模型而赋予旧地图、采集、NPC 或原作身份。
- 人格、通话记录、音色、库存、状态和存档按 `activeConversationScopeId` 隔离。人格随模型 ZIP 迁移，通话主角 ID 在克隆包时重绑目标模型；读档后旧异步请求失效。
- 生图接口与密钥属于设备；生图任务及图片存储在 `image_generation_v1/<scope>/`，目前不随模型 ZIP 打包。闹钟音频也是设备文件，迁移设备需重新选择。
- 保留 Android 包名 `com.ateleragent.studio`、MCP callback `agentatelier-fishmcp://oauth/callback` 及 Windows 已有数据目录身份。技术兼容 ID 和用户历史文本不批量改名。
- 更新定义只接收 `OAA_UPDATE_CONFIG_BLOB` / `OAA_UPDATE_CONFIG_KEY`，由包装脚本显式传 `-UpdateConfigDefinesPath`；旧配置密文不被接收。
