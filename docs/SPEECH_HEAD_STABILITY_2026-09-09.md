# 说话时头部抖动修复

日期：2026-09-09。

## 确认的问题

1. Android 无 WAV 包络时使用约 5.2 Hz 的模拟嘴型；之前同一个 energy 同时影响嘴型、原资源头身驱动强度和额外摇摆幅度，所以嘴巴开合会带动头部反复改变幅度。
2. 额外摇头使用播放器位置作为相位；位置事件会校正时间，每段 TTS 又从零开始，容易产生姿态跳变。
3. 原资源 driver 和额外正弦层同时写头、颈、身体；语音能量越阈值和自动定时器又可以插入随机组合动作。
4. 流式解析忽略 `action:none` 但增加标签计数，会再次触发先前的非空动作。

## 已修改

- 头身驱动与逐音节能量解耦，嘴型保持原有同步逻辑。
- 删除额外正弦摇头层，使用连续帧时间推进原资源的目标、过渡、停留和部位跟随。
- 说话强度使用独立平滑包络：待机 0.30、说话 0.85；起始响应 350 ms、结束响应 500 ms，触摸/主动视线接管时平滑抑制。
- 切换主导部位时，从各部位自己的当前姿态开始衔接；避免把头的目标突然转交给身体或眼睛。
- 缺少可识别的旧版 driver 时使用小幅、慢速的目标与停留回退。不假称已经解析新版 `GesturePatternDefs`。
- 连续 TTS 句间只暂停口型，保留头身状态与眨眼周期；表情相同不在每句重新应用。点击反馈结束和换装完成后恢复面部定时器。
- 讲话期间暂停自动随机组合动作及音量峰值触发的手势，保留 LLM 明确指定的动作。
- 组合动作保留原始 Alpha 和 Speed，不再对固定 Alpha 做 easeOutQuad 放大，也不再额外叠加自设情绪速度。
- `action:none` 明确覆盖上一动作，不产生新的动作播放。
- 程序控制骨骼后使用 `Physics.pose` 重算世界姿态，应用本帧已有物理偏移，不重复推进物理时间。

本地 Spine 包实际在动画应用前调用 `onBeforeUpdateWorldTransforms`，与其部分注释不同。因此保留现有基姿恢复回调的位置，避免误把恢复操作移到动画写入之后。

## 原版资源仍可继续利用的部分

- `expressionSets`：原配眼睛、眉毛、嘴型的完整组合，可替代当前手写的小表。
- `mixDurationEye` / `mixDurationEyebrow`：按情绪采用不同过渡时长，例如旧坐姿 sad 为 0.58 秒、happy 为 0.24 秒。
- `armInOutPartConfig`：手臂进入/退出中间姿势与双臂错开时序，适合进一步改善跨姿态手势。
- `fixedGestureBindingsByAttitude`：按情绪区分赞同、否定和提问，避免每次固定选同一动作。
- 新版 `AttitudePatterns` / `GesturePatternDefs`：按说话状态与交流意图选择注视、头部和身体模式；需要另行实现格式兼容，不能只判断 schemaVersion。

这些是进一步优化项，本次没有重建全套表情系统或手臂路由。外层只有 APK 资源配置和编译产物，没有完整原版 Dart 调度源码，不宣称逐帧复刻。

## 验证

- 驱动、流式动作和视线相关 15 项测试通过。
- 现有 TTS、表情、姿态、组合动作相关 31 项测试通过。
- 新增检查覆盖音量脉冲不影响头身轨迹、平滑进入/退出、主导部位切换、10,000 帧有界无漂移、缺失驱动回退及 none 不重播。
- 修改过的 Dart 文件静态分析通过。
- ADB 未发现设备；未进行真机视觉或真实 TTS 试听验证，也未构建新 APK。

建议设备复测：普通模式和 ASMR 各播放一条多句回复，包含安静停顿和一次情绪变化；观察句间头部是否突然跳位，以及播放期间点击人物、切换坐姿/站姿后的恢复。
