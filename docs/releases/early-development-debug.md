当前为 **1.0.0 早期开发测试版（Debug，构建号 1）**，适合体验与反馈。

### 更新内容

- 独立应用 AgentAtelier，支持用户导入 Spine / Live2D 模型。
- 导入时扫描资源并通过 LLM 生成、审阅动作和表情映射。
- 每个模型独立保存人物、用户与世界设定、聊天、记忆、状态、音色和存档。
- 名称、头像、提示词和通知跟随当前模型；改善切换模型时的 ASMR 隔离。
- 保留虚拟手机、翻译、可选 TTS、记忆整理及 PC Agent 联动入口。

### 使用方法

1. 安装附件中的 `OpenAgentAtelier-1.0.0-dev.1-debug.apk`。
2. 在设置中配置 LLM，使用模型导入入口选择 ZIP，审阅映射后确认导入。
3. 设置人物与世界信息；语音需另外配置 TTS 和音色。模型与档案可导出为 ZIP 备份。

### 注意事项

- **Debug 模式可能导致卡顿、耗电增加及不稳定，不代表正式版性能。请先备份，在测试设备使用。**
- 不内置人物模型，请自行准备有权使用的资源。VRM 尚不能播放；Spine 3.6 仅 Android JSON。
- 在线 LLM、映射、翻译与 TTS 需要自行配置服务，可能产生费用。PC Agent 需兼容桌面端与 HTTPS 中继，后台推送需额外配置。
- 本次提供 Android Debug 包，适用 arm64-v8a / x86_64；没有新增 Windows 安装包。
