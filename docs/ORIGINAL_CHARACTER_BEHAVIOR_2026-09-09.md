# 原资源角色表现接入（2026-09-09）

当前版本优先使用本地已打包的两套可动角色 gesture 配置，减少额外随机动作。本文记录本轮实现，前面的 `CHARACTER_RESPONSE_COMPARISON_2026-09-09.md` 是修改前的分析快照。

## 已接入

- `character_resource_behavior.dart` 读取 `EmotionProfilesV4.normal` 的完整表情组合。坐姿 622 组、站姿 108 组，包括配对的睁眼、闭眼、眉毛和嘴部；动画 stem 在当前骨骼中解析和校验后使用。
- 眼睛和眉毛使用原情绪各自的混合时间；说话口型使用对应 `lipSyncScrubClip`，继续保留较小的嘴部权重和开合范围。
- 表情在相邻 TTS 片段之间保持，句间只关闭嘴。眨眼使用当前组合的闭眼片段，变更表情不会与眨眼恢复互相覆盖。
- 原 `baseAnimTimeScale` 控制基础动画速度。遵守 `fixedBasePoseMode`，关闭自动随机换基础姿势；用户仍可手动换姿势。发送消息和撤回消息不再额外改基础姿态。
- `acknowledge → agree`、`disagree → deny`、`think → question` 按当前情绪的原始正权重动作表选择。最后一个是 Demo 的语义适配，不是原始 LLM 协议。
- 自动手势只选当前情绪有正权重的组；最近动作耗尽可以重复合法组，不能绕回零权重组。保留同组变体的概率归一化。
- 读取 `ApplicableSittingIDs`，当前自动和语义播放仅允许普通坐型兼容动作，排除盘腿专用组合。保留完整手动动作列表，实际播放也校验兼容性。
- 同一时刻只播放一项语义／自动手势，已有动作及退出混合尚未结束时跳过新请求，不积压过时动作。语义动作间最少 3 秒是 Demo 的保守调度规则。
- 手势执行时平滑抑制附加头身 driver；音节响度仍只控制嘴，不驱动头部抖动。
- 触摸表情等待原触摸动画时长和退出混合结束后恢复，不再固定 1.35 秒抢回面部轨道。换服装时取消旧触摸回调。
- LLM 提示词默认 `action:none` 保持已有神态，只在明确交流节点触发动作，不强迫每句轮换。

## 调度取舍与未复刻部分

外部文件是 APK 解包资源，没有完整原版 Dart 播放器源码。因此这是依据配置重建的版本，不能称为原应用状态机逐帧复刻。

表情细节保持 6–10 秒、眨眼 1–5 秒、说完后保持 5–8 秒和串行手势策略是本应用的调度选择。没有声称从资源恢复了这些完整时序。

`fixedGestureBindingsByAttitude.eye` 已保留数据，本轮没有另加一套强制眼神控制，避免和现有 driver、触摸追踪叠加。手臂经中间姿势路由、`PoseTypeSets` 独立类型状态及 weak/strong 视觉档尚未完整接入。姿态专用手臂权重已支持显式 `poseType` 参数；当前不能仅凭一个 idle 名称猜测其属于 freehand 还是 resting。

目前两套可动资源仍使用 `DriverDefs`。外部新版服装的 `AttitudePatterns/GesturePatternDefs` 尚不属于当前可动服装链路。本轮没有导入或发布这些资源。

TTS 情感程度和句内演出密度仍独立控制声音，不会被用于增加全身动作频率。
