# 长期记忆台词污染修复（2026-10-13）

## 问题与原因

记忆页出现日文原始台词、`[happy]` / `[emphasis]` 标签和被截断的句子。代码检查确认，本地事实兜底直接保存命中关键词的台词；`happy` 会触发情绪记录，日文 `好き` 会误触发关系转折，50字符硬截断又丢失后半句。旧记录缺少译文时，页面也没有提供补写入口。

## 改动

- 共用记忆文本清理器，去除已知语音、表情、动作标签及内部推理/工具块，保留普通方括号内容。
- 本地提取只记录明确事实并注明人物归属；问题、假设、未接受请求、单独瞬时情绪不直接升级为长期事件。同一句命中多个类别只保存一项。
- 最近/长期模型摘要使用界面语言及第三方视角。保留完整句子，异常过长或无效的新候选使整批整理失败，不推进游标。
- “马上整理”可重新整理旧本地条目，也可在没有新对话时补齐缺失译文。修复优先读取来源对话；没有原文时只概括现有片段。用户确认后才提交。
- 确认保存一次提交长期记忆、最近记忆和进度，失败不部分保存。手改摘要标记为手动来源，自动整理保护原文。
- 记忆卡片显示来源与旧版本提示，支持补写译文；确认修复后摘要和译文即时更新。

## 使用

设置 → 数据管理 → 记忆 → 马上整理。检查“待确认长期记忆”中的重新整理项和补译文项，按需修改，然后保存记忆与译文。取消可保留现有记录。
