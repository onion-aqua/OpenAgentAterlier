# AgentAtelierR 1.0.4.1 MCP FishAudio

## 更新内容

- Android、Windows 同步 Fish Audio MCP 改进。选择 `drama-3` 时，使用官方成对标签：`whisper`、`emphasis`、`soft`、`fast`、`slow`、`stress`、`forceful`，保留情感强度与标签密度设置。
- 减少多余喘息和长停顿，避免本地音量处理放大轻微呼吸；改进语音时长判断、静音与损坏音频检查。
- 修复单段音频异常导致后续台词停止、预取错误、取消后的残留请求和播放问题；完善 Studio 文本块与音频结果核对。
- 修复声音设置页重建时的滚动状态崩溃。
- 保留持续 ASMR 语言与翻译修复，以及普通/ASMR 独立音色设置。
- Android 保留通话自动静音、通话结束恢复，以及“莱莎一直陪在你的身边哦”后台陪伴通知。

## 使用方法

1. Android 覆盖安装 APK；Windows 解压完整 ZIP 后运行 `AgentAtelierR.exe`。
2. 在“设置 → TTS → Fish Audio MCP（OAuth）”登录、读取工具列表并选择模型，填写普通/ASMR 音色后点击“保存并使用 MCP”。选择 `drama-3` 即启用新标签；ASMR 音色留空时沿用普通音色。
3. 持续 ASMR 跟随“设置 → 语言”；“独立翻译”控制译文生成方式。不翻译或相同语言时隐藏译文。可按需调低感情程度和标签密度。
4. Android 后台与通话设置位于“设置 → 声音 → 后台陪伴与通话静音”。按需允许通知、来电识别、自启动和后台运行。

## 注意事项

- 喘息处理可减少诱发与放大气声，无法保证消除模型生成的全部呼吸声或纠正发音。
- MCP 付费生成提交后，音频异常或结果不明时不会自动重复生成或回退 API；连续两段无效音频会停止后续合成。
- 指定模型使用 Story Studio，“服务默认”使用普通 TTS。Studio 会在云端保存台词和音频，模型与积分以 Fish Audio 账号权益为准。
- 第三方语音/视频通话识别及后台运行取决于手机系统支持。
