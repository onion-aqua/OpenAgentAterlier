# OpenAI 兼容接口配置槽位

在“设置 → AI 接口 → OpenAI 兼容接口”顶部选择配置 1、2、3。每个槽位分别保存 Base URL、模型名称和 API Key。

- 原来的配置和 Key 自动作为配置 1 使用，其余槽位初始为空。
- 切换槽位保留本次未保存的编辑；点击“保存”后，保存本次编辑并启用当前所选槽位。
- “取消”或系统返回会放弃未保存编辑，包括尚未保存的 Key 清除操作。
- Key 输入框留空会保留该槽位原有 Key；“清除 Key”只标记当前槽位，保存后生效。
- 空槽位不会借用配置 1 的 Key。使用需要认证的服务时，请填写对应 Key。
- AI 对话启用开关为全局设置；Gemini、TTS 和角色设定槽位不受本功能修改。

地址和模型保存在本地偏好 `openai_configurations_v1`，并可随原有本地备份导入导出。Key 使用系统安全存储 `openai_slot_keys_v1` 单独保存，首次读取兼容原 `openai_api_key`；Key 不进入普通偏好、备份或日志。

每个请求开始时固定服务商、地址、模型和所选槽位的 Key。同一轮后续的记忆整理沿用这组配置，避免请求过程中切换槽位导致密钥与地址混用。
