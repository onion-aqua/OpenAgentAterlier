# 模型导入与操纵模板

安装包只保留操纵模板和渲染运行库，不包含 Spine 角色骨架、图集、贴图、座椅或场景模型，也不包含 Live2D 人物模型。未导入模型时会显示导入提示，聊天可以照常使用。

## 使用入口

1. 打开模型库；虚拟手机中的「模型姿态」提供模型选择入口。也可从「设置 → 模型档案与数据 → 导入模型或模型与数据 ZIP」导入。无模型时可点主界面的「导入模型」。
2. 导入原始人物资源时选择 Spine 或 Live2D；恢复应用导出的模型档案时选择「模型与数据 ZIP」。场景/座椅使用独立选项。
3. 完成资源扫描、LLM 映射和确认后，在模型库选中模型并点「切换」。

所有已导入的 Spine、Live2D 模型显示在同一个模型库中。用户设定、人物设定、世界设定、聊天、记忆、状态和存档跟随模型，不再由莱莎/苏菲两个应用角色开关决定。旧资源的角色归属字段仅用于兼容已有存储路径。

应用在私有目录的 `model_packages/<modelId>.zip` 中保存模型资源和该模型的应用数据，同时保留供播放器快速加载的展开缓存。「模型档案与数据 → 导出模型与数据 ZIP」可携带对应模型换设备恢复；普通聊天/设置导出仍不携带模型资源。完整范围、排除项与旧数据迁移规则见 [模型档案与独立数据](model_workspaces.md)。

## Spine

新人物资源的入口会先运行「本地目录扫描 → LLM 映射 → 用户审阅 → 确认导入」。详见 [模型导入映射](model_mapping.md)。既有本地模型与操纵模板继续保留。

ZIP 至少包含同一基础名称的三个文件：

```text
my_model.atlas
my_model.skel               # 或 my_model.json，二选一
my_model.png
my_model_gesture.json       # 可选，作为已有人工映射的依据
preview.png                 # 可选，独立预览图
```

支持 Spine 4.2 二进制或 JSON 骨架；Android 另支持 Spine 3.6 JSON，自动选择独立的离线 WebGL 运行库，不改写骨架版本，也不影响原有 4.2 原生播放。3.6 二进制及其他平台的 3.6 播放暂不支持。单张图集贴图，ZIP 和展开内容各不超过 64 MB。图集必须引用同名 PNG，尺寸须一致。导入前使用对应版本运行库解析模型，3.6 还会验证实际绘制，确认映射声明的基础 idle 动画和其他绑定真实存在。

已知绑定的模板及包内 gesture 可提供语义证据。新导入映射不要求莱莎专用的动画名称，通用模型采用自己的控制数据。

保留七套原有模板：常服坐姿、常服站姿、黄色泳装、黑色泳装、休闲 T 恤、蓝白短裤、紫色旗袍。模板只包含控制映射数据，没有骨架、图集和图片。它们适用于对应的兼容绑定，不能让任意骨架自动获得相同动作。

应用仍保留高层语义、表情、身体区域检索、姿态/轨道冲突检查和动作配方。只有当前模型真实包含且姿态兼容的动画会成为规划候选；缺失动作不会被当作已完成。旧的莱莎专用配方也必须通过实际骨骼动画检查后才可使用。

## Live2D

将一个完整的 `.model3.json` 模型目录压成 ZIP，包含其引用的 `.moc3`、贴图、动作、表情、物理和姿态文件。支持 Cubism 3 及以后导出的 model3 格式，ZIP 中只能有一个 model3 入口。源工程 `.cmo3` 不能直接作为运行模型导入。

在 model3 文件旁放置 `performance.manifest.json`，为动作、表情和参数指定语义：

```json
{
  "actions": {
    "wave": {"group": "Greeting", "index": 0, "description": "抬起右手轻轻挥手问候"}
  },
  "expressions": {
    "happy": {"name": "Smile"},
    "neutral": {"name": "Neutral"}
  },
  "parameters": {"mouthOpen": "ParamMouthOpenY"}
}
```

`group`、`index`、表情名称与参数 ID 必须来自该模型。manifest 可省略；新导入时应用仍先读取原始目录、运行 LLM 映射并等待用户确认。已有本地模型沿用旧 manifest 和保守的精确名称匹配。对于编号式动作或特殊手型，必须补充真实语义描述才能准确选择，不能仅凭模型文件推断全部含义。详见 [Live2D 接入说明](live2d_integration.md)。

## 场景与座椅

使用独立的「场景 / 座椅 Spine 包」导入；未导入时采用静态背景且不创建座椅模型。包格式、场景 ID 和限制见 [场景导入说明](external_spine_scenes.md)。

## 开发验证

当前 Live2D 原生运行库对应 Android 7.0（API 24）及以上的 arm64-v8a / x86_64 构建；不生成缺少该运行库的 32 位 APK。Windows 使用 x64 运行库。具体工具链与本地准备流程见 [运行时说明](live2d_runtime_patch.md)。

用户资源不会回退到安装包中的加密模型。`tool/build_protected.ps1` / `tool/run_protected.ps1` 不再生成角色资源包或要求角色资源密钥；仍保留私有 PC Agent 配置的准备流程和 release 混淆。

需要真实目标模型验收渲染、参数范围和动作语义。目录/导入/假 transport 测试不能替代 Android、Windows 上的实际模型显示检查。
