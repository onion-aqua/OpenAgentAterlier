# MiMo TTS 配置与实现

入口：设置 → 语音合成 → MiMo TTS。

1. API 地址默认为 `https://api.xiaomimimo.com/v1`，也可填写完整 `/chat/completions` 地址。
2. 填写 MiMo API Key。留空保留已保存的密钥；密钥单独保存在系统安全存储，不写入日志或导出配置。
3. 选择合成模式：
   - **参考音频克隆**：`mimo-v2.5-tts-voiceclone`。选择 MP3 或 WAV 参考音频，不需要创建 Voice ID。
   - **预置音色**：`mimo-v2.5-tts`。填写 `mimo_default`、`冰糖`、`茉莉`、`Mia`、`Chloe` 等官方音色名。
   - **文字设计音色**：`mimo-v2.5-tts-voicedesign`。必须填写音色描述，例如“年轻女性，声音清亮，中文口语自然，语气亲切而有活力”。
4. 可填写演绎指令。感情程度控制整体表达强度，句内演出密度独立控制已有句内标签的保留数量；这两项是应用的提示词适配，不是 MiMo 官方数值参数。
5. 修改试音文字，点击右下角“试音”。也可打开“以 ASMR 模式试音”比较效果，该开关不改变主页当前语音模式。
6. 点击下方“保存”，将 MiMo 选为当前 TTS 服务。打开“AI 回复后自动播放”后，莱莎台词接入原来的分句播放、表情、口型、取消及重播链路。

## 参考音频

参考音频经 Base64 编码后不得超过 10 MB。应用按 `4 * ceil(原始字节数 / 3)` 检查，并采用 10,000,000 字节的保守阈值；原文件建议小于 7.5 MB。不要直接沿用其他服务“原文件小于 10 MB”的规则。

选择音频时复制到应用支持目录的 `mimo_references/`，避免系统选择器临时路径过期。只有试音或聊天合成时才向配置的 API 发送音频。取消设置会清理本次未保存的参考文件和试音文件。

配置导出包含模式、地址、演绎指令及参考文件名，不包含音频本体、本机绝对路径或密钥。导入后必须重新选择参考音频、按需填写密钥；应用不会信任备份中的任意本机文件路径。

MiMo ASMR 沿用同一音色，通过独立的 ASMR 演绎指令控制轻声和耳语，不需要第二个 Voice ID。

## 请求与播放

- 使用 `/chat/completions`，演绎指令放 `user`，台词放 `assistant`。
- 聊天和试音均读取设置中的“莱莎回复语言”，在 `user` 指令中明确发送中文、英文或日文的发音要求，不跟随界面或翻译语言。官方当前示例没有单独的 `language` 字段，因此不添加未文档化参数；试音文字请使用所选语言。具体语种效果仍取决于服务端能力。
- 克隆音频通过 `audio.voice` 的 `data:audio/...;base64,...` 传入。
- 当前使用非流式 WAV，解码 `choices[0].message.audio.data` 后校验容器再交给现有播放器。
- 日志记录模型、文本、演绎指令、状态与音频字节数；省略二进制 Base64 和密钥。
- 官方文档目前注明克隆和音色设计暂不提供低延迟逐块音频输出。本实现使用已有的分句合成和预取，不声称实现服务端低延迟流式播放。
- 官方格式约束与请求结构已经通过模拟服务器测试；未填入用户密钥进行线上合成，声音效果和设备端解码需实际试音确认。

来源：[MiMo V2.5 TTS 官方文档](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5)。

代码入口：`mimo_tts_config.dart`、`mimo_tts_client.dart`、`mimo_tts_settings.dart`，以及 `app_controller.dart` / `ai_services.dart` / `chat_screen.dart` 的服务接入。
