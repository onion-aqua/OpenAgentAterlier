# 角色身份改造：当前阶段

OpenAgentAtelier 以用户导入的模型为角色入口。每个模型各自保存人物设定、世界设定、用户设定、聊天、记忆与存档。模型名称、资源文件名和操纵模板不构成角色身份的证据；缺少的信息保持未设置，不自动补成原有作品背景。

## 当前模型的显示与运行

- 聊天、历史、语音闹钟、模型入口和加载画面使用当前模型的名称；头像读取导入模型预览，缺少预览时使用名称首字或通用人物图标。
- 未导入模型时显示中性入口。旧存储中的 `ryza` 或 `sophie` owner ID 不会自动启用旧人物、设定、地图、NPC 或音色。旧用户资料和聊天仍保留，并记录无模型工作区的恢复快照。
- 当前模型尚未配置地图、商店或任务时，虚拟手机显示未配置说明；天气保持未设置，不估算原作品地区天气，也不自动播放其背景音乐或环境音。
- 背包使用当前模型的独立库存和记录，直接通过虚拟手机访问；没有接入世界工具时，只能查看或使用已有物品，不自动启用采集、调合或聊天入包。
- 正常与 ASMR 音色由当前模型设置决定。空音色不回退到内置人物；NPC 文本也不能仅凭旧 owner ID 激活原作品的头像或固定音色。
- Android 常驻通知标题为 OpenAgentAtelier，正文使用当前模型名称；模型切换、改名或恢复前台会同步。服务重建且尚未同步角色时使用通用陪伴文字。
- 持续 ASMR 按模型工作区隔离。切换时停止并清除旧音频、译文和主题，旧异步结果不能写回新工作区。

## 对话内部协议

- 主角使用固定标签 `主角：`，英文兼容别名为 `protagonist:`。界面上的显示名由当前模型档案提供。
- 旁白使用 `旁白：`，NPC 使用 `角色[id]：`，译文使用 `译文：`。NPC 的 ID 与主角的角色身份分别处理。
- 独立翻译请求中，主角的 `speaker` 为 `protagonist`；NPC 保留自己的 ID。
- 新的语音、表演、翻译和语言纠正结果重建正文时使用通用主角标签。持续 ASMR 不朗读角色标签，也不向翻译器注入固定作品人物。
- 记忆与语言校验识别通用主角标签，避免把协议标签当作正文或让辅助模型重新指定角色身份。

## 旧数据兼容边界

旧的 `ryza`、`sophie` 等 ID 仍可能出现在存储命名空间、语音路由、解析接口及旧存档中。旧中文、英文、日文角色前缀仍可解析，以保证已有对话和导入数据可读。它们仅用于兼容，不能用于给导入模型推断姓名、世界观、头像或音色。

本阶段不批量改写已有聊天或记忆。无需纠正的既有原文继续保留；用户主动触发翻译、语言纠正、语音或表演处理时，新生成的处理结果采用通用协议。原文查看仍保留历史内容的原始身份描述。

旧作品专用的地图、NPC、商品、音效、人物资源、授权署名与操纵模板仍可能存在于项目或迁移资料中。本次是运行路径和角色身份的逐步解耦，尚不代表这些文件已全部物理删除。后续清理需先区分用户导入资产、兼容数据、资源授权要求和当前模型实际使用的能力。

## 验证覆盖

`test/protagonist_protocol_test.dart` 覆盖旧名称与通用主角前缀解析、NPC ID、翻译请求身份、翻译及语言修复重建、持续 ASMR 和本地确定性记忆。现有语音与表演测试继续验证台词、控制标签、旁白、译文和 Unicode 文本的保留。

`test/generic_character_identity_test.dart`、`test/model_identity_ui_test.dart`、`test/chat_screen_model_import_test.dart` 验证无模型入口、同 owner 的独立模型、名称与头像同步及世界入口；`test/generic_npc_voice_test.dart`、`test/generic_soundscape_test.dart` 验证固定音色与旧世界音频隔离；`test/android_companion_identity_test.dart` 与 `test/continuous_asmr_companion_test.dart` 验证通知身份同步及 ASMR 晚到回调隔离。
