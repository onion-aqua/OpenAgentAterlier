# Fish Audio 语音异常适配

普通聊天与持续 ASMR 自动使用以下处理，无需额外开关。Fish Audio API 与 MCP 共享输入清理；显式模型仍通过 MCP Studio 的 `default_backend` 设置。

MCP 选择 Drama 3 时使用官方局部成对标签，详见 [Drama 3 标签适配](FISH_AUDIO_DRAMA3_TAGS.md)。

## 减少多余喘息

- 新的语音提示词要求轻声、清晰、连贯地朗读，不鼓励喘气或长段呼吸表演。
- 发送前清除喘息、吸气、呼气及叹气等表演标签，合并耳语标签，限制停顿标签和重复标点。保留正常台词、情绪及日语词内促音；显示文本与存档不因此改写。
- Fish 音频的低音量窗口不再获得大于 1 倍的本地自动增益，避免抬高轻微呼吸和底噪。保留原始轻声台词，不通过裁切波形去除呼吸。
- 只有气声标签而没有正文的请求会在提交前拒绝。

这些处理降低诱发和放大气声的机会，不能保证删除模型已经生成的全部呼吸声，也不能仅凭音量判断错字或漏字。

## 时长、音频与分段播放

- 时长评估使用本次实际发送的文本、语言、有效语速、有限停顿预算与 ASMR 状态。MCP 未暴露实际语速控制的路径按正常语速评估，不把界面设置当作已经生效。
- 轻度超过预期只记录诊断，明显超长才拒绝。42 字日语回归样例中，19 秒允许播放，71 秒拒绝；这不是所有台词的固定阈值。
- PCM 时长按真实采样帧计算，不再受 RMS 窗口取整或 Android 初始时间戳影响。Windows 压缩音频可通过独立静音播放器准备并读取时长；不启动播放。不支持波形分析时，不宣称已经验证静音或呼吸内容。
- 拒绝无法解码、无效采样或接近数字静音的音频，真正低音量的耳语保留。
- 已确定无效的单个片段可跳过，继续后续片段；连续两个无效片段停止后续合成。持续 ASMR 的失败片段保留文字和译文卡片，禁止播放。
- 普通聊天、缓存重播与持续 ASMR 都支持 Android 文件来源失败后改用同一份音频字节准备播放，不重新生成语音；播放器异步错误会结束当前片段并停止残留播放。
- 预取错误立即接收，轮到该段时再处理；取消后清理晚到的预取文件，并阻止再次发起合成。

## 请求与诊断

- MCP 付费生成提交后，不因本地音频检查失败而自动重新生成，也不回退到 API。Studio 返回结果必须对应本次文本块；缺少身份时只读补查，不能确认就停止。
- API 模式保留原有的无效音频最多重试一次逻辑；连续失败限制还会阻止继续合成长篇余文。
- 402、认证失败、网络异常和生成结果不明不能作为普通坏音频跳过并继续提交下一段。
- 时长诊断记录语言、有效语速、预期/实际毫秒数及判断原因，不增加正文、音频 URL 或凭据日志。

## 验证边界

此次验证使用离线假 transport、合成 PCM 测试音频、Flutter 测试与 Android 原生单元测试。没有调用收费语音生成，没有实际试听；云端音色与发音改善仍需后续试听确认。

回归测试同时发现并修复声音设置页的折叠状态与滚动位置存储键冲突，避免页面重建时出现 `double` 被读取成 `bool` 的错误。
