# 对话语言与上下文

## 主聊天语言校验

此前的角色回复语言、旁白语言和翻译语言已被写入各分支的提示词，设置与备份也有保存，但主回复没有正文语言校验；独立翻译只检查 JSON、序号与标签结构，没有检查译文语言。

本轮补充以下行为：

- 一轮开始时捕获回复、旁白、翻译语言，设置变化只对之后的新消息生效。
- 流式输出仍会逐步显示；流结束后分别检查角色台词、旁白和内联译文。
- 只有明确的错语证据才触发一次定向纠正；修复保留原意、人物、人名和表演标签，不重新运行原聊天或工具，避免重复修改背包、任务或地图。
- 纠正通过后才完成回复保存，并进入表情、动作和语音规划。仍错语或返回无效结构时提示失败，不播放这条不合格回复。
- 独立译文也检查目标语言，结构或语言失败最多重试一次；内联译文缺项时使用既有翻译模块补全。译文和原文一起保存。
- 已保存历史再次朗读时也检查明显语言不符；不合格台词跳过 TTS。
- 辅助纠正与翻译各有 90 秒整体等待上限，包含 Gemini 请求与底层重试的等待；翻译第二次尝试也共享这段预算。NPC 流式接收结束后取消接收阶段的计时器，纠正使用自己的超时，避免接收阶段剩余时间使其提前失败。

校验支持中文、日文、英文，采用文字与常见语法证据。短句、人名、引用和中日文共用汉字词保守处理，不承诺识别所有语言错误；正常回复不会因为检查多发一次模型请求。只有触发纠正或缺失译文补全时才会增加请求。

新逻辑位于 `lib/src/dialogue_language_guard.dart`、`lib/src/chat_screen.dart` 和 `lib/src/auxiliary_llm_tasks.dart`。NPC 私信使用同一校验基础，独立语言设置见 `docs/npc_messages.md`。

## 持续 ASMR 的语言与译文

2026-10-18 检查发现，持续 ASMR 原先绕过了原文语言校验、没有读取独立翻译开关，并将“不翻译”错误回退到界面语言。同语言时复制原文到译文，加上播放页无条件显示译文占位，导致中文原文下方再次出现中文。

现在持续 ASMR 在确认主题时固定本次角色回复语言、翻译语言和翻译方式；所有朗读原文（包括叙述性内容）及 TTS 均使用这份语言设置。主聊天独立的“旁白语言”不会把 ASMR 的叙述切换成另一种语言。设置变更对下次确认主题生效，缓存音频重播沿用原片段及译文。

| 设置 | 持续 ASMR 行为 |
| --- | --- |
| 独立翻译开启 | 先生成、检查朗读原文，再单独翻译对应片段。 |
| 独立翻译关闭 | 主模型一次生成对应的原文和译文，逐片段校验并分开保存。 |
| 翻译语言为“不翻译” | 不请求译文，不显示译文或等待译文提示。 |
| 翻译目标与朗读语言相同 | 跳过翻译并隐藏重复区域。 |

稿件先清理控制标记、角色前缀及意外译文，再逐片段检查语言。只对明确错语进行一次定向纠正，保留语音提示标签；仍不合格时不进入 TTS。主模型附译使用有明确对应关系的短片段，格式错误允许一次整理，不能把同一整篇译文重复附到多个音频。独立译文沿用现有的结构、序号与语言检查，不用原文冒充失败的译文。

“独立翻译”用于选择翻译方式，并非译文显示总开关。要完全关闭译文，应将“翻译语言”设为“不翻译”。语言判断对短语、人名和中日共用汉字仍采取保守策略；本地模拟测试不等于线上模型或音色已经通过试听验证。

## 已有上下文管理

当前已有上下文裁剪与两层记忆整理：

| 范围 | 普通模式 | 长上下文兼容模式 |
| --- | --- | --- |
| 主聊天原始历史 | 最近 16 条，18000 字符预算 | 最近 8 条，6000 字符预算 |
| NPC 私信原始历史 | 最近 24 条内的完整回合，18000 字符预算 | 最近 24 条内的完整回合，6000 字符预算 |
| NPC 相关旧消息片段 | 7500 字符 | 2400 字符 |

主聊天启用长期记忆后，每 4 个用户轮由 LLM 整理最近记忆，重要承诺等可提前触发；累计 8 条尚未整理的最近记忆后，再整理长期记忆。它用于保留故事事实，不是逐句保存全部对话。NPC 保留完整私信记录，按最近消息和当前问题关键词查找旧内容，不把其他 NPC 或主角的记忆混入。

**目前没有单独的滚动对话摘要压缩功能。** 超出上下文窗口的原始消息不会整段发送，主聊天依靠最近与长期记忆补充，NPC 依靠旧消息检索。记忆整理未开启或失败时，较早主聊天内容可能没有进入模型提示词。历史字符预算不等于系统提示词与图片在内的总 token 上限。

本轮补上了 NPC 原始历史的字符预算：以前仅限制 24 条，一条很长的回复也可能使请求过大。裁剪不删除已保存的 NPC 私信。
