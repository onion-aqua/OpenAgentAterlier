# 设定槽位与主题（2026-09-15）

## 快速切换设定

用户设定 → 称呼与自画像、角色与世界 → 人物卡、角色与世界 → 世界书，
各提供独立的 5 个槽位。旧版本正在使用的内容保留在槽位 1。
新槽位从对应的默认设定开始，不复制其他槽位的自定义内容。

点选槽位，编辑后点击“保存并使用”：同时保存本次编辑过的槽位，
并启用当前选中的一份。编辑时来回切换不会丢失临时草稿，取消或返回则不保存。
人物卡、世界书的“恢复默认”只修改当前编辑槽位，保存后才生效。
仅当前槽位参与既有提示词注入流程；语言、动作、ASMR 控制规则和原有
人物/世界书注入开关保持独立，不会把所有备用槽位发给模型。

槽位保存到本地设置 `settings_slots_v1`，完整数据导入导出包含
`settingsSlots`。老备份没有此字段时，从导入后的当前设定建立槽位 1。
游戏进度存档仍遵循原来的边界，不替换用户的服务配置和设定槽位。

## 主题与半透明页面

界面与场景 → 主题色：翡翠绿、琥珀橙、星海蓝、薰衣紫、蔷薇粉、香槟金、
石墨灰。点选立即应用，和浅色/暗色/跟随系统独立。初始使用翡翠绿。
按钮、开关、滑块、选中状态、发送按钮与玻璃高光使用同一套色彩方案。
暗色模式提供更亮的强调色，并保留可读的文字对比。

炼金工坊与任务页现在与设置页一样，显示于活动场景上方；聊天控件暂时隐藏，
人物和背景继续活动。玻璃开关开启时模糊背景，关闭时使用普通半透明材质。

主要实现：`settings_slots.dart`、`settings_slot_selector.dart`、
`app_controller.dart`、`settings_screen.dart`、`character_prompt_editor.dart`、
`app_theme.dart`、`app_shell.dart`。不引入额外依赖或资源素材。

## 安卓返回导航

根页面通过 `page_navigation.dart` 记录页面切换历史。安卓返回键或返回手势
优先关闭顶层弹窗/编辑页，其次收起全局菜单，再返回设置分类或大地图，最后
退回前一个功能页。明确选择“角色聊天”会清空页面历史；只有聊天首页且没有
待关闭的界面层时，才允许系统退出。根页面统一处理返回，避免多个 `PopScope`
同时响应导致一次手势跨过两层。隐藏 UI 时，返回先恢复 UI。
