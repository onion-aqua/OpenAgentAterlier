# 1.1.1 角色资源接入核对（2026-09-17）

## 核对结果

本地 1.1.1 APK 解包目录的常服坐姿和站姿，各自的 skel、atlas、PNG、gesture.json，与开发目录对应文件 SHA-256 相同。无需覆盖文件。坐姿有 9 个情绪配置、622 条 normal 表情组合、140 个动作组；站姿分别为 9、108、53。组合数量不是独立贴图数量。

## 当前执行链路

- `ProtectedCharacterAssets` 解密当前皮肤资源，保留本地导入皮肤兼容路径。
- `CharacterResourceBehavior` 读取 `EmotionProfilesV4` 的完整眼睛、闭眼、眉毛、嘴型组合及权重。LLM 情绪标签决定情绪池，实际动画名称仍由当前骨骼解析；说话时嘴部优先由音频驱动。
- 本次让表情轮换在待机时继续运行，按照资源姿势重选时间设置保守间隔（至少 6–10 秒）。待机时同步更新嘴型，触碰和动作占用期间推迟切换。该调度是本应用的适配策略，不宣称等同原版内部调度。
- `CharacterPerformanceProfile` 本次读取 `projectConfig.ambientGaze` 的 yaw、pitch、roll 边界，约束驱动目标；无配置皮肤保持原有范围。未将这些归一化边界用于裁剪原始骨骼动画。
- 原有 `DriverDefs` 与 `ambientBindings` 驱动待机、头部和身体跟随。缺失字段由本地待机参考补足，显式空列表保持禁用。
- 原有风轨道按资源 `windAnimationPrefix` 查找动画，场景风强平滑过渡。场景强度是本应用配置，不是原版天气映射。
- 保留骨骼原生物理约束；每帧先还原上一帧程序偏移、应用动画、加入动态偏移，再推进一次物理，避免叠加漂移。

## 验证与边界

静态检查通过，表情组合解析、待机绑定、动态边界、过渡与风包络相关 30 项测试通过。不是原版运行时的逐帧复刻；视觉风格与真实 TTS 联动仍需实际试玩确认。

资源、加密包、密钥和安装包不提交源码仓库。打包仍使用 `tool/build_protected.ps1`，Android 使用既有 debug 签名以支持覆盖安装。
